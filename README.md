# Stickly

Offline Android reminder app. React + TypeScript + Vite UI, packaged with Capacitor.
Scheduling, notifications and reminder storage are **native Kotlin** (AlarmManager, Room, receivers),
so reminders fire when the app is closed.

See `docs/BUILD.md` to get started, `docs/TESTING.md` before release, `docs/PLAY_STORE.md` to publish.
